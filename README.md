# Data Cleaning and Preprocessing – Diabetes Dataset

This project demonstrates data cleaning and preprocessing using Python and Pandas.

## Dataset

Diabetes dataset containing 768 records and 9 columns.

## Tools Used

- Python
- Pandas
- NumPy
- Google Colab

## Cleaning Steps

- Checked dataset structure and data types
- Identified invalid zero values
- Converted invalid zeros to missing values
- Filled missing numerical values using the median
- Checked and removed duplicate rows
- Standardized column names
- Performed final data validation

## Final Dataset

- Rows: 768
- Columns: 9
- Missing values: 0
- Duplicate rows: 0

## Files

- `diabetes_cleaned.csv` – cleaned dataset
- `Data_Cleaning_Diabetes_Task1.ipynb` – Python/Colab notebook
